# Kenshin's Mix & Master Workspace

Professional mixing and mastering, done to a strict, measured standard.

| Start here | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | **Core rules every agent must follow** (auto-loaded via `CLAUDE.md` / `GEMINI.md`) |
| [`.claude/skills/pro-mix-master/`](.claude/skills/pro-mix-master/SKILL.md) | Full standard: gated workflow, how to derive every setting per song, QC gate, DSP guardrails, feedback dictionary, learning loop, delivery |
| [`deliveries/LEARNINGS.md`](deliveries/LEARNINGS.md) | Lessons notebook: read before every song, add after |
| [`deliveries/`](deliveries/) | Each song's masters, alternates, A/B clips, report and session scripts |
| [`docs/Pro_Mix_Master_Standard_v1.docx`](docs/Pro_Mix_Master_Standard_v1.docx) | The whole standard as one Word document, to share with any agent (regenerate it when the standard changes) |

**Rule 0: every song is a new project.** No presets. Every value is derived from the song's own measurements, its reference and the artist's intent.
