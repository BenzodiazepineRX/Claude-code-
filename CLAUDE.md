# Claude instructions for this repository

This repository is Kenshin's mix & master workspace. **The rules below are mandatory for every mixing or mastering task here.**

@AGENTS.md

## Claude-specific

- Before any mix, master or revision, **load the project skill `pro-mix-master`** (`.claude/skills/pro-mix-master/SKILL.md`), read the references it points to, and read `deliveries/LEARNINGS.md`.
- Working tools from past sessions (analysis, harmonic-envelope resonance finder, rider, pocket EQ, limiter gain-reduction meter, QC gauntlet) are in `deliveries/<Song>/session/`. Reuse the *tools*, never the *settings*: re-derive every value for the new song.
- Put intermediate audio in the scratchpad. Put deliverables in `deliveries/<Song_Name>/`. Commit and push deliverables to the session branch.
- Kenshin is a visual learner who prefers simple, detailed, reassuring explanations: send loudness-matched A/B clips and pictures, give timestamps, and never sound judgmental.
- Update `deliveries/LEARNINGS.md` at the end of every song and after every round of artist feedback.
